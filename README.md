# ❤️ 11:11 — Our Special Moment

✨ A Little Wish, A Special Person.

A beautiful, interactive and responsive romantic website created to make 11 November at 11:11 a little more memorable.

## 🌙 Features

- ✨ Magical 11:11 welcome screen
- 💌 Interactive surprise envelope
- ❤️ Five special wish questions
- 🌸 Personal wish-sharing section
- 💖 Heartfelt secret message
- 🌟 Animated stars and floating hearts
- 🎵 Optional background music
- 📱 Fully responsive design
- 💾 Save wishes using Local Storage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
